# LinkedIn Query Strategy

Use this reference when a deep search needs more coverage than the daily core queries or when choosing a rotating adjacent family. Do not run every query in one session. Select the smallest set that covers the requested role families and recent tracker gaps.

## Selection Rules

- Start with the four daily core queries defined in the skill.
- Check the most recent tracker tab and rotate toward a family not searched in the previous run.
- In a Daily Light Run, add at most one adjacent family.
- In a Deep Search Run, select queries across the requested primary families before adding adjacent searches.
- Prefer narrower technology-and-scope combinations over broad titles when the result pool is noisy.
- Treat query result counts as coverage signals, not evidence that individual jobs fit.
