# Reference Memory

`references/` is the repo's shared source-of-truth layer. Skills read these files at runtime so personal context can stay current without copying it into every `SKILL.md`.

## Current Reference Files

- `candidate-profile.md`: compact candidate profile, positioning, evidence calibration, and interview/job-search assumptions.
- `career-targeting.md`: target role families, priorities, and screening logic.
- `github-project-signals.md`: project evidence that can support job matching, resume tailoring, and interview prompts.
- `job-search-sources.md`: canonical job-search trackers and source links.
- `linkedin-filters.md`: reusable LinkedIn filter notes.
- `linkedin-query-strategy.md`: expanded query inventory and search strategy.
- `resume-2026.md`: current resume source used for scoring, tailoring, and coaching.
- `engineering-interview-drills/`: targeted interview drill references for backend and AI-product topics.

## What Belongs Here

- Durable facts that multiple skills should reuse.
- Personal profile, resume, project, and career-targeting context.
- Job-search source locations and stable search strategy.
- Drill material that supports repeatable interview practice.

## What Does Not Belong Here

- One-off job descriptions unless they become reusable examples.
- Temporary search results that belong in a spreadsheet or task report.
- Private credentials, cookies, session data, or secret URLs.
- Agent scratch notes that have no future operational value.

## Privacy Rule

Treat reference files as sensitive. Do not quote more private detail than needed in final responses, and do not copy private reference content into public-facing skill instructions unless the user explicitly wants that behavior.
